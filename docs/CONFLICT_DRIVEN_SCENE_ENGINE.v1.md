# 冲突驱动场景引擎 V1.0

Conflict-Driven Scene Engine｜默认方法层，不是新入口，不是台词拉长器。

短剧生成和审校默认按本文执行。用户不必每次再教「台词写长一点」。
不换 `video_kingdom_entry`，不换 Provider，不改前端结构。
旧合同缺省不阻断。新剧/原创桌关键冲突场按本文建模。

## 一句话

不是写对话，是让人物互相施压。一段对话有没有价值，不看字数，看结束时关系、信息、选择或行动有没有变。

普通生成：提问 → 答完 → 推进。信息传递完整，情绪没交锋。
冲突生成：目标冲突 → 试探 → 施压 → 反击 → 关系变化。

## 生成前先建场

内部明确，不必写进观众稿：

- 这场要改变什么
- A 的诉求、底线、藏着的东西
- B 的诉求、底线、藏着的东西
- 双方争的那一件具体东西（利益、情感、秘密、身份、承诺、责任、选择）
- 哪些信息现在能露，哪些必须暂时藏
- 收场必须发生的那一项变化

缺对抗点，先改人物目标，不准靠堆台词过关。

## 三种机制（拆开用，不整段套模板）

### 1. 潜台词

表层台词 ≠ 真正要争取、隐藏或试探的东西。
角色不能无理由一次说清。反问、回避、讽刺、沉默必须有动机。
不准为了悬念让人说不合逻辑的废话。直说时要有失控、决裂、坦白或迫不得已。

### 2. 情绪递进

「挑衅 → 隐忍 → 加码 → 爆发」只是一种曲线，禁止每场机械套用。
每一层必须比上一层改变至少一项：信息、空间、代价、称呼、物件、选择。
把「你很无耻」换成「你真的很无耻」再换成「你全家都无耻」= 重复攻击，不是升级。

### 3. 信息差

双方知道的不一样。同一句话可以有两层理解。
角色不能使用自己尚未获得的信息。悬念建立在已铺的线索和动机上，不靠无依据神秘化。

## A / B / C 三类场

| 类 | 何时 | 对话 |
| --- | --- | --- |
| A 高冲突 | 身份暴露、情感决裂、利益对抗、真相逼问 | 允许多轮，情绪要铺垫和变化 |
| B 推进 | 交代任务、确认线索、协作 | 简洁，但留个性和因果 |
| C 动作转场 | 追逐、异象、关键物件、突发 | 视听承担叙事，少废话 |

短剧不是每段都要长。关键冲突不能在情绪刚建立时被一句话解决。冲突已经完成、再说只会重复，就用行动、沉默、反转或切场收束。

## 分轨

- 《残荷诡影》正史：因果见光、守界归位。冷落在日子里的不对劲。禁止空洞地府阎王，禁止超自然虐恶现世报灌进正史。
- 冷爽原创桌（《退席》《试工》）：讨厌的人可以被他自己的规矩反噬。
- 对话鬼故事（《别应》）：日常异化 + 开场认知反差。别人的外卖骑手、厨房奶奶、吃绝户舅舅不进我们的人。
- 示例里的林墨/周培只说明机制，不写进残荷正史。

## 接到制作链（不停在生成）

1. 对话情绪是否撑得住声音表演？同一句「你回来了」可以是责问、惊喜、冷淡或试探。剧本必须让 `speech_intent` 读得出来。见 `docs/VOICE_CONTROL_DEFAULT.v1.md`。
2. 对话是否能在画面里完成？反应镜头、动作、物件特写、距离变化、留白、环境声。不要两个人对着说到底。

动作要可拍、有功能：停顿=权衡；避开视线=回避或克制；收回手=关系变了。禁止堆「眼神一冷」「空气凝固」。

## 审校八问

1. 双方有没有明确且互相冲突的目标？
2. 有没有潜在意图或真的情绪拉扯？
3. 有没有没有新作用的重复台词？
4. 情绪是不是按人物动机和事件压力走？
5. 动作和停顿可不可演、可不可拍、有没有戏剧功能？
6. 有没有不合理的全知或强行隐瞒？
7. 结束时关系、信息、选择或行动有没有有效变化？
8. 有没有根据的悬念或情绪余波？

缺冲突，先修正人物目标与情境。
