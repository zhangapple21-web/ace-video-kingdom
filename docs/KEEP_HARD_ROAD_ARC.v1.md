## 一句话

爽感来自「公平被质疑 → 坚持被验证」，不来自开挂、围观打脸、金句升华。

速记：**卡死 → 劝退 → 守住 → 做实 → 见光 → 归位 → 留白**

原句「遇阻→被劝→不妥协→踏实做→成了→点透→立住→走远」可用。
禁止把原帖七段句式整段填进角色嘴里。

## 七环是弧，不是每场作业

| 环 | 作用 | 单场 | 一集/一段弧 |
| --- | --- | --- | --- |
| 立困 | 具体卡点摆到眼前 | 常要 | 开篇必有 |
| 加压 | 权威 / 众人 / 捷径把路堵死 | 高冲突场要 | 必有 |
| 守择 | 拒绝捷径，做最难但最对的 | 咬住「不肯将就」 | 人设立住 |
| 深耕 | 细节做实，信物/手续/分寸落地 | B/C 场常见 | 反转才可信 |
| 破局 | 结果说话 | 不必每场 | 弧的兑现 |
| 证道 | 原则在动作里，不靠演讲 | 残荷默认不写金句 | 冷爽最多一句短的 |
| 余韵 | 干净收束，不报复不暴富 | 收场留白 | 必有 |

单场通常只完成 1–3 环。B 类推进场做到「加压或守择 + 有效变化」即可。
禁止为了跑完七环灌水、拖探案、每场证道。

## 分轨怎么用

### 残荷正史

- 立困：日子里的不对劲（契、税、信、锁、地短一截），不写空荡荡地府阎王。
- 加压：规矩显得合理。户房只管契、冬至期限、众人劝「别较真」。捷径是认账、拔锁、画押、绕开塘北。
- 守择：不拔、不进、不坐、不销空名。沉默选择，不赌气演讲。
- 深耕：信物链要动。日期对上、抄本、当票、井栏，细节越实，见光越硬。
- 破局：因果见光、账落地、地权后果出现。不是全场安静、不是围观震惊。
- 证道：守界归位。原则写在动作里，不写「该是什么样就得是什么样」这种作者金句。
- 余韵：灯灭、空册退出、棋摆一半。不写众人道歉、不写报复、不写暴富。

残荷禁止：耳光砸玻璃、系统金手指、战神归来、炫富认祖、超自然现世报、吃绝户、霸凌网红。

### 冷爽原创桌（《退席》《试工》）

七环可以压进一集。讨厌的人可以被他自己的规矩反噬。
破局仍要「结果先于反应」，不嘲讽、不阴阳把格局做小。
证道最多一句短的，对着事不对着骂人。
别人的外卖骑手、厨房奶奶、吃绝户舅舅不进我们的人。

### 对话鬼故事（《别应》）

立困=日常异化的第一眼反差。加压不必三人劝退，规则自己咬人。
破局不是打脸，是认知再也装没看见。

## 吸收 / 不吸收

吸收：

- 开篇就用具体失败，不用空泛抱怨
- 给主角留轻松退路，主角主动不走
- 阻力要显得稳妥、合理、大多数人的选择
- 守择用动作，不辩解不争吵
- 深耕决定爽得可信还是离谱
- 先亮结果，再给反应
- 余韵回归本分，留留白

不吸收：

- 七段参考句式整段套用
- 每场「全场安静了」「怎么可能明明说过做不到」
- 每场证道金句
- 把「专业校准打磨一丝不差」写成说明书
- 用七环顶替活人三问、有效推进、冲突驱动

## 和冲突引擎的接缝

加压场、守择场、破局场，优先走 A 类高冲突：人物互相施压，收场必须改关系 / 信息 / 选择 / 行动之一。
深耕、余韵可以走 B/C 类，少废话。
提问答完就推进，仍算失败。

## 审校（ADVISORY）

1. 这一集/这一弧有没有具体卡点，还是只有气氛？
2. 有没有看起来合理的退路，人物有没有主动不走？
3. 守择是动作还是演讲？
4. 深耕有没有落到可看见的手续、物件、分寸？
5. 破局是结果见光，还是围观打脸？
6. 有没有多余金句、作者升华、报复收尾？
7. 残荷有没有被写成冷爽现世报？
8. 有没有为了跑完七环而注水？

缺弧，先改人物要什么、不肯放弃什么。不准靠套公式过关。
