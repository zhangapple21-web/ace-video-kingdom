# 创作开发框架 v1

这份框架吸收了外部 AI 漫剧工业化流程中真正能提高创作质量的部分。它是视频王国唯一入口生成的 `creative_development_profile.v1.json`，属于创作开发层和只读规划层，不是第二个生产入口，也不能绕过剧本审查、导演/反例/连续性审计、五关收据或 Agnes 准入。

## 已吸收

- 输入分类：原创故事、小说、剧本、改编、世界观、人物设定、分集大纲和镜头需求。
- 人物全集、关系/阵营/冲突图，避免只读主角而漏掉会影响连续性的配角和关系。
- 角色十项记忆提示：标志动作、表情、镜头、配色、语言、服装元素、道具、情绪、出场和反差。
- 角色标签到可见行为、表情、台词和镜头的映射。
- 角色弧线：初始状态 → 事件刺激 → 情绪/行为/关系/价值变化 → 阶段性终态。
- 视觉世界规则：时代、地域、建筑/技术或魔法、色彩和光线基线。
- 单集节奏检查：开场钩子、早期冲突、信息变化、情绪升级、反转/回收、结尾问题、角色记忆度和生成可行性。
- 长线 40/60/80 集规划作为可选输入，不强迫每个项目扩写集数。

## 与现有生产链的映射

```text
creative_development_profile
  ├─ character_roster / signatures / arcs
  │    └─ Character Identity + persona card + State
  ├─ visual_world
  │    └─ Scene State（场景默认动态构建，按需使用构图静帧）
  ├─ episode_structure
  │    └─ 剧本审核 → 分镜/Shot State → 提示词合同
  └─ quality_review
       └─ 编剧、导演、反例、连续性审计与五关收据
```

角色包仍然锁定身份，不锁死一张构图；本镜起始状态由 Shot State 决定；场景由 Scene State 动态构建。视频生产仍走 `Video → agnes-video-2.5-flash`，图像资产按需走已验证图像路由和受证据约束的降级。

## 明确不吸收为硬规则

- 固定每部作品必须 40/60/80 集。
- 固定每集必须 120 秒或固定 0–5/5–20 秒时间表。
- 强制输出英文提示词；中文可执行提示词优先，英文只是可选派生物。
- 把十项记忆点、世界观字段或角色全量扫描变成每个镜头的阻断门。
- 让创作层直接决定 Provider、跳过双审、跳过五关或静默改写用户剧本。
- 用“95% 常见剧情模板”替代真实剧本和实际收据。

## 状态与门槛

- `PENDING`：结构已创建，内容仍可补全；不阻断研究/规划。
- `DRAFT`：已有用户或编剧内容，等待双审。
- `READY`：创作层字段齐全，但仍必须经过生产合同和五关。
- `LOCKED`：用户采纳并锁稿；任何实质改动必须产生新版本和 supersedes 关系。
- `ARCHIVED`：历史参考，不可作为当前生产输入。

`production_integration` 永远为 `false`。创作开发层只能提供结构、候选和审计线索；Approved State、角色资产、场景/镜头合同、音频主时钟和 Provider 收据才是生产事实。
