# 通用镜头节奏与专业标注 v1

这是一套跨项目的镜头设计标准。它描述“为什么用这个镜头、演员怎么完成节拍、何时切换”，不把某一集的人物、手机、对白或固定秒数写成全局规则。

## 默认字段

每个镜头现在都应填写：`shot_purpose`、`scale`、`transition_intent`、`script_annotations`、`performance_beats`、`timing_basis`。剧本标注包含动作、对白、情绪、潜台词、动机和氛围；表演节拍包含说话时手和身体在做什么、听者如何反应、什么时候停顿、独白时嘴部状态、为什么此处切镜。

景别按叙事目的选择：远景交代地点和处境，中景承载对白与动作，近景放大情绪，细节特写只用于有故事意义的眼神、手或道具。远景—中景—近景是覆盖基础，但不要求每个场景机械凑齐。

## 节奏规则

对白先保证听清和表演完整，再决定切点；冲突可以缩短反应间隔，独白和情绪沉淀可以保留停留。镜头变化必须有信息、情绪或空间动机。单镜仍保持一个主要视觉动作，内部切镜交给后期装配。时长以实测音频或动作完成为依据，固定“三秒一切”、一句一景和同景别上限都只是提示，不是硬门。

## 运镜等级（全局方法，不是新入口）

提交「镜头：」时填写两项可选字段，缺省不阻断旧合同：

- `camera_motion_level`：`NONE` / `SUBTLE` / `SIMPLE` / `COMPLEX`
- `camera_motion_reason`：为什么要动

铁律：

1. 无理由不推机。对白默认 `NONE` 指的是摄影机不要自己飞，不是把人拍成静帧。短剧给观众看，画面里必须有可看变化（表情、手、听者、道具、空间压力）。只有权力、信息、距离、情绪或注意力变化时才升级运镜。
2. 「镜头：」必须是一条具体运动 + 一句理由。禁止「电影感推进」把摄影决策权交给 Agnes。
3. `COMPLEX` 必须写清 start / trigger / path / focus / stop，对上 `photography.camera_path` / `speed` / `focus_handoff` / `landing`。
4. 失败先降摄影，不改对白、不改剧情、不换模型：`COMPLEX → SIMPLE → SUBTLE → NONE`。只降 `camera_motion_level`，禁止把景别塌成证件照 / MCUSTATIC。
   禁止用「拉远工位静帧」冒充看见环境。那会变成更远的活照片，不是中景表演。
5. 本方法挂在现有 `shot_rhythm` 上。V2 ≠ 新入口 / 新技能 / 新 Shot Core / 新审批层 / 替代双审五关。

写法示例：

- `NONE`：镜头：固定机位；人物说话时手和身体有具体变化，听者有可见反应；理由：本镜重点是对白与表情，不需要改变观看距离。禁止只写自然微动作导致两张图在挪。
- `SUBTLE`：镜头：SUBTLE_PUSH，极轻微推近；理由：人物得知关键信息后，逐渐收紧观众对其反应的注意。
- `SIMPLE`：镜头：SIMPLE_TRACKING，跟随人物从门口走到桌边，镜头保持侧后方关系；理由：交代人物移动路径与空间关系。

## 观看密度 / 禁止无信息垫秒（全局方法，不是新硬门）

完整性轴已经有了：装不下就拆镜或延长，不吞词、不加速、不截断。现在补上对称的密度轴：

```
请求时长 = 实测对白/独白音频
         + 唯一主要动作完成
         + 有观看任务的反应（默认建议 0.4–0.6s，不是必须垫到这个数）
         + STOP
```

铁律：

1. 两句台词拍成 5–6 秒可以成立，但多出来的每一秒必须能回答「观众新得到了什么」。答不出 = 拖长失败。
2. 有观看任务的停（听者反应、信息落地、关系/权力变化）可以留；台词结束后无新信息的发呆、慢走、空推、假停留禁止用来填满 `duration_seconds`。
3. 反应留白 0.4–0.6s 是建议，不是必须垫到的下限。没有反应任务就不要垫。
4. Provider 生成了 6 秒 ≠ 创作时长。生成后剪掉死气；不要发明业务去填满请求秒数。
5. 缺省字段 `underfill_policy=trim_or_shorten_never_pad`、`hold_reason`。旧合同缺这两字段不阻断。
6. 不准为了短而吞词、加速或截断对白。失败时缩短空秒，不改剧情完整性。

切了没新信息 = 结束或与下一拍合并，不要靠空秒撑满。

短剧不是动画静帧：禁止把镜头做成两张参考图互相挪动。NONE 可以固定机位，但表演、听者、道具或空间必须有观众能看懂的变化。有吸引力的停（眼神、手、权力落地）算观看任务；没变化的发呆才算垫秒。

## 分阶段完善

潜台词、动机、氛围仍是现役必填标注。焦距、机位高度、镜头路径、速度、焦点交接、落点和色温 K 值已升为可选默认层（shot_rhythm.photography / color_temperature_k）：新镜头建议填写；未知写 UNKNOWN，禁止编造毫米级焦距或假 K 值。缺省不阻断旧合同。构图参考、主辅光/色板、BGM 进入、音效卡点、留白秒数、码率/帧率/色彩空间/字幕规范仍留在 later，分别在镜头稳定、调色、混音和交付阶段启用。

## 验收

统一入口在提交前调用 `tools/validate_shot_rhythm.py`。缺少核心目的、专业标注、表演节拍、运动动机或音频锚点会阻断；固定切点只产生警告。外部资料只提供镜头语言参考，生产仍受角色锁、场景锁、连续性桥、音频主时钟和创作约束包控制。

Adobe 的镜头序列资料把远景、中景、近景和视线/屏幕方向作为叙事连续性的基础，并指出剪辑节奏由镜头时长和切换节奏共同控制；本项目吸收这些结构性原则，保留自己的音频主时钟与单镜门禁。[Adobe 镜头与角度指南](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles.html)；[Adobe 镜头清单指南](https://www.adobe.com/creativecloud/video/discover/shot-list.html)

## 提交句：动作先于镜头（全局方法，不是窗口记忆）

别人能拍、我们像两张图在挪，差不在摄影字段多少，而在 Agnes 真正吃到的那句话。

官方 Flash 提示顺序是：主体场景 → 动作与变化 → 镜头 → 风格 → 一致性。reference 模式示例是「以 Picture 1 为角色参考，角色在花田中自然奔跑，保持外观」；keyframe 才写「从首帧姿态转身走向窗边，平滑过渡到尾帧」。身份锚图走 reference，不是 first_frame/last_frame。

把官方顺序压成我们现有的「镜头：」：

1. 这个人此刻做什么（可命名动词：举手贴耳、放下杯子、转头看门口）
2. 听者 / 道具 / 空间有什么可见变化
3. 一条运镜 + 一句理由（NONE 也可以，但 1+2 不能空）
4. 保持外观（参考图锁身份，禁止两张锚图互变）

毒句黑名单：历史合同校验可保留 warning 以便复盘；新 production 提交由 `production_shot_gate` 直接阻断「自然微动作、轻微呼吸、电影感推进、同一帧、重复帧、无动作、MCUSTATIC、证件照」等静态表演描述。旧合同只能作为历史收据，不能重新提交。

对白镜默认仍是 NONE/SUBTLE：摄影机不要自己飞，但说话时手或身体、听者反应必须有可看变化。没有观看任务就 STOP，不要用空秒或静帧插值填满 5–6 秒。


## 这些字段是为了人还在，不是为了表填完

焦距、运镜等级、观看密度都是壳。短剧给人看：有欲望的动作、听者的变化、值得停的那一拍。表填完但人没活，仍算失败。经验记在 research/soul_shot_ledger.v1.jsonl，不另起路由系统。

## 身份包不是电影画面（全局方法）

角色包是长期资产：脸、体型、基础服装、角色绑定道具，需要提前准备。场景不是必须预制图库；Scene State 由剧本和前后镜动态建立（同一套房子、空间关系、时间光线、家具风格）。道具默认当镜状态，角色绑定道具除外。Character Identity 不等于 Scene State 不等于 Shot State。湿发、哭过、这一集换装、这一镜坐姿，不写进永久身份包。Agnes 2.5 Flash 对白短剧默认 mode=reference，images[] 只绑本镜出场人物的原图身份板。不要把身份包写入 first_frame / last_frame，也不要走 ti2vid 把参考图做成视频。禁止只塞一张脸裁图当整场画面。不要把每个场景先做一张图当成开拍条件。

需要让观众看见这间办公室、这个机位时：
`input_images` 默认只绑角色包**原图身份板**（本镜出场人物的 `PACK_ORIGINAL` / 用户最初原图）。Agnes `mode=reference` 仍可能把 Picture 1 当画面源，所以原图只锁身份，不是构图主图。下面这些图 **整列不得进入 `input_images`**，不是「别放第一张就行」：

- 身份裁图 / `PACK_FRONT` / `CROP`
- 工位人像静帧 / `WORKSTATION_POSE`
- 空镜 / `WORKSPACE_EMPTY`

「两张原图」是角色包身份板的数量，不是每镜必须交两张图：单人镜绑该角色原图，双人镜绑两个角色原图。工位/空镜属于场地锁和 Scene State 文字，不塞进 images[]。看见环境靠 Scene State + 提示词里的表演中景（腰以上、手、桌面同框），不靠场地图，也不靠把人缩小到房间里对口型。`gpt-image-2` 作图仍是 look-dev；没人审通过的构图静帧不要当视频源。失败只降 `camera_motion_level`，禁止加回工位/空镜/CROP。

作图静帧不是成片。视频模型要演戏，不是把静帧轻微抖动。拉远静帧 ≠ 看见环境。下一镜只吃 Approved State，不吃最新未审帧。锁身份不等于只锁一张脸裁图。场景连续性靠 Scene State，不靠场景参考图库。

## 证件照对口型不是短剧（全局方法，不是新硬门）

角色包锁身份，不锁构图。两张正面裁图互切对口型，看起来像证件照在说话，不是短剧。

铁律（缺省不阻断旧合同）：

1. `input_images` 只绑本镜出场人物的原图身份板。CROP / PACK_FRONT / WORKSTATION / WORKSPACE_EMPTY 整列不得进入 images[]，不是「别放第一张就行」。原图只锁身份，不是构图主图，不得当 first_frame。看见环境 = 中景空间里的表演（腰以上、手、桌面同框，人在做事），不是把人缩小成远距离说话图，也不是把场地图塞进参考。
2. 对白/电话/双人至少一镜看见环境。看见环境不是远景活照片：人必须在空间里完成可命名动作。MCU / 中近景可以有，不是全剧默认拍法，也不是「第一镜必须建立镜头」的死规定。
3. 失败先降摄影只降 camera_motion_level，禁止把景别塌成证件照 / MCUSTATIC，禁止用「拉远」冒充看见环境，禁止加回工位/空镜/CROP。
4. 正反打可拆，不可拆成两张角色包对口型；至少一侧过肩或半身。
5. 历史合同可保留 warning：脸占满、MCUSTATIC、证件照、第一帧就是中近景。「不要全身 / 不要远景」不是一律毒药——合法特写仍允许近景；新 production 命中静态毒句由 `production_shot_gate` 阻断。
6. 每一镜写工位/台灯/墙是项目场地锁，不是全剧必填。通用层只要求 Scene State：在哪、什么光、站位怎么连。
7. 对白时长走音频主时钟；禁止垫秒填最短时长。已有密度轴，不另升拒绝生成。

这是现有 shot_rhythm 的方法增量。不换入口，不换 Provider，不替代双审五关。
