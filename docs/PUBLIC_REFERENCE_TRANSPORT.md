# Agnes 公网参考图传输

Agnes `agnes-video-2.5-flash` 的参考图字段要求 Provider 能从公网读取图片。这里需要配置的是“参考图传输层”，不是把项目目录、脚本或整个 D 盘暴露到公网。

## 当前做法

- 一次性/受控探针：只上传本次任务允许的参考图片，生成短时公网 URL。
- 提交前：用 `tools/record_reference_transport.py` 或对应刷新脚本逐张执行 HTTP GET，校验状态码、`Content-Type`、字节数和 SHA-256。
- 提交时：只把已通过校验的 URL 写入 `first_frame`/`images` 字段。
- 提交后：保留收据，按图床能力删除临时对象；不上传脚本、合同、密钥或其他项目文件。

## 长期生产配置

长期使用时应配置 S3/R2/OSS 等对象存储的短时签名 URL（建议设置过期时间和最小读取权限），并将存储桶、前缀和保留策略放在本机环境变量或部署密钥管理中。不要把永久公开 URL、访问密钥或桶配置写入 Git。

## 当前边界

`run_short_clip.py` 已拒绝把本地路径伪装成 Agnes 2.5 Flash 的公网参考图；本地文件必须先经过明确的上传/传输步骤。没有可读公网 URL 时，任务应停在准入门禁，不能直接 POST。
