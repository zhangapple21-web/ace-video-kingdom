# 第一镜内置声音与外置克隆音频公平对照

A 组保留 Agnes 内置音轨；B 组使用 CosyVoice 3 生成独立音频，传给 Agnes 作为参考，并在后期混入同一条外置音频。两组使用相同台词、角色参考图、视频模型和三次重复次数。

逐句记录音色自然度、音色稳定性、实际时长、停顿、口型同步、漏字和三次重复一致性。评测者在不知道 A/B 身份的情况下打分，不能用“接口 completed”替代听感或口型验收。

B 组必须先有按角色切出的参考片段；整段混合音频不能直接当成老张或文姬的克隆样本。测试合同见 `research/ab_tests/SHOT_01_audio_ab_test.v1.json`。
