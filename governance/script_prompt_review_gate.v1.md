# 开拍前唯一检查表

做视频只走这一条：`$video-kingdom` → `video_kingdom_entry.py` → 开拍总流程 → Agnes。检查表措辞、题材触发、配音分层以后可微调；不准换生产入口、不准换默认 Provider、不准跳过双审原文结论。扣子/其他插件不是生产入口。

【自动前置】用户只发剧本正文即可，不用写流程说明或「旧记录作废」。收到新剧本/改了台词或剧情 = 新一轮：对话里的旧「通过」「合格，可以生成」、旧 COMPLETED、旧 run_id 一律当没跑，从编剧「剧本审核意见」开始。只改提示词或运镜 = 不换剧本，只重做导演审核。没贴本轮剧本 = 停在剧本审核前，不准用上一轮剧本或旧审核顶替。作废不等于删除：旧收据留盘作历史，不得批准本轮。

本文件是开拍前的唯一检查表，不是旁路。它把编剧导演双审、开拍五关和扣子公开链路映射到现有入口。四步双审是本项目门禁，不是扣子未公开的后台原流程。对话层和机器门禁都必须遵守。旧 COMPLETED、旧审核意见、其他镜头或其他 run_id 一律不得冒充本轮已审。没有新剧本时停在剧本审核之前。不接入扣子插件/官方故事板，不引入扣子积分/套餐硬门。

## 不允许跳步

1. 规格与素材先齐：主题、平台、画幅（创建后不改）、风格、对白/字幕/BGM、角色锚图、场景道具、音色。资产须清晰、无遮挡、绑定正确镜头，肖像/品牌/版权落到角色包 + 公网 URL + privacy_scan。落到创作简报和角色包，不另建素材库。
2. 收到剧本后，先以编剧身份输出「剧本审核意见」。剧本层只审叙事，不审运镜/起止状态：
   - 对白顺序对不对，归属是否是角色名（禁止「男声/女声」）
   - 独白怎么处理（后期闭嘴叠，不对口型）
   - 时间线、人物动机、跳场漏场
   - 有没有明显拍不了或会穿帮的点
   - 有没有账号、密码、链接等敏感信息
   - 手机状态：仅当剧本涉及手机/通话/界面时启用专项；《张铁铁的沙雕日常》/电话剧情默认启用。不涉及则 phone_state 写「本镜不涉及手机」
   - 结论只能是：通过 / 不通过（不通过必须写原因）
3. 剧本审核结论为「通过」后，才允许写分镜执行提示词/合同（起止状态、运镜原文、禁止项、参考图绑定）。不通过时禁止写提示词，禁止生成。参考图必须绑定公网 URL，不能只写「参考这张图」。
4. 提示词写完后，再以导演身份输出「提示词审核意见」——审的是分镜执行是否歪曲剧本：
   - 有没有歪曲剧本
   - 硬规则有没有写全
   - 题材触发的高风险描述（亮屏、完整接听、画中画、聊天UI、视频通话）
   - 结论只能是：合格，可以生成 / 不合格需修改
5. 只有导演明确写出「合格，可以生成」，才允许进入五关收据和视频生成。否则先改，再审，不准拍。
6. 五关必须是本轮新收据：`role_room.py --execute` + `continuity_bridge`、锚图哈希、音频主时钟、`camera.movement` 原句、`video_kingdom_entry` → `production_shot_gate`。
7. Provider completed 不等于成片。正式对白短剧独立配音；快速小样可用模型内置声音；无对白动作镜可只做环境声/音效/BGM。字幕、混音和技术+创作 QC。审片闭环：标记问题 → 归纳方案 → 用户确认 → 局部重做。画布=本地对比/关键帧；剪辑=时间线/字幕/混音。不引入扣子画布。

## 剧本 vs 分镜

| 层 | 审什么 | 不审什么 |
| --- | --- | --- |
| 剧本审核 | 叙事、对白归属、人物、时间线、独白分轨、敏感信息、可拍性 | 运镜、起止状态、参考图绑定 |
| 分镜+提示词 | 起止、运镜、时长、参考图、禁止项 | 不得改对白归属或剧情结论 |
| 导演审核 | 分镜执行是否歪曲剧本、硬规则、题材触发风险 | 不得用旧审核冒充本轮 |

## 配音按项目

- 正式对白短剧：独立配音时间轴，先锁配音再排镜头。
- 快速小样：允许模型内置声音。
- 无对白动作镜：环境声/音效/BGM。
- 不把「所有视频必须先独立配音」写死。时长服从实测音频+动作完成；0.4–0.6s 是默认建议，不是绝对值。装不下则拆镜/延长/改写，不加速吞词。

## 状态机只映射现有 7 步（不另建状态机文件）

DRAFT → 1 规格与素材；SCRIPT_REVIEW → 2 剧本审核；STORYBOARD_DRAFT + PROMPT_AND_CONTRACT_REVIEW → 3–4 提示词/合同与导演审核；PRE_FLIGHT_CHECK → 5 五关收据；SHOT_GENERATION + SHOT_QC → 6 单镜小样；ASSEMBLY_AND_EDIT + AUDIO_AND_SUBTITLE + FINAL_QC + EXPORT_AND_DELIVERY + POSTMORTEM → 7 后期交付。

## 扣子准备项怎么落到现有入口（吸收，不接入扣子）

| 扣子说法 | 落到 | 不吸收 |
| --- | --- | --- |
| 项目目标/画幅 | `creator_workflow.py` 简报；画幅创建后不改 | 扣子项目对象 |
| 完整剧本与对白归属 | `script_prompt_review.script_review`（叙事层） | 要求原始剧本先写齐运镜/起止 |
| 故事板确认后再生成 | 导演「合格，可以生成」+ 五关收据 | 扣子故事板插件当生产入口 |
| 角色场景道具参考图 | 角色包两张锚图 + 《接粉风云》场地锁四张图（`user_workspace_lock_manifest_20260917.json`）+ 公网参考图传输层 | 未绑定的「参考这张图」空话；工位图不覆盖身份锚图 |
| 快速小样 vs 正式配音 | 按项目：正式对白短剧独立配音；小样/无对白例外 | 全片硬前置独立配音 |
| 画布对比/审片局部重做 | 本地 QC 标记 → 方案 → 确认 → 局部重做 | 扣子画布/剪辑器 |
| 隐私版权 | `privacy_scan` / `scan_sensitive_content.py` | 把真实账号写进画面 |
| 额度套餐 | 本机密钥 + Agnes 锁定，不静默换模型 | 扣子积分/订阅套餐硬门 |
| 聊天动画把文字交给 HTML/Canvas | 仅显式 `chat_ui` 模式 | 套到《张铁铁的沙雕日常》 |

## 机器证据

镜头合同必须带本轮 `script_prompt_review`，字段绑定 `shot_id`、`run_id`、`script_hash`、`prompt_hash`。

- 校验入口：`tools/validate_script_prompt_review.py`
- 生产阻断：`tools/production_shot_gate.py`
- 模板：`assets/templates/script_prompt_review.v1.json`

提示词改了就必须重做导演审核；剧本改了就必须从编剧审核重跑。提交 prompt 若含「完整接听 / 接听过程 / 亮屏 / 拨号 / 男声说 / 女声说」等动作描述，即使导演写了通过也阻断。phone_state 以「本镜不涉及手机」开头时，跳过电话类高风险词，仍扫描「男声说/女声说」。
