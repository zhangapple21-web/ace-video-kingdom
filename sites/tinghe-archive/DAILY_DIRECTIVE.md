## 0. 真源与硬性规则

- 剧稿真源：`D:\视频创作\ace-video-kingdom\sites\tinghe-archive\originals_source\<work_id>\work.json`。
- 不得修改、删除或重排任何已存在的 `work_id` 目录；只**新增**或**在某作品的 `episodes` 里追加新集**。
- 新集 `no` 必须是连续整数、从上一集号 +1 起；缺集不可编号。
- 每集必须：`k:"scene"`（且全文仅此 1 处）+ `k:"cast"` + 若干 `k:"para"/"k:"line"` + 结尾唯一一个 `k:"hook"`。
- 未知块类型（如 `psychology`）一律不许出现；`blocks` 必须是非空数组。
- 人物、场景、对白均须可视化、可拍、少地点少角色；不要内心独白占篇幅。
- 爽点是 压迫→亮牌→震惊→对手崩塌，分层：小反派→中级→大 BOSS。
- 积累前，先运行 `py -3 build_originals.py --check-only` 确认现有稿全部合法；不合法就**只**修复格式问题（不改剧情），不产出新稿。

## 1. 今天产出什么

## 2. 写前：生成/刷新前文上下文包（强制）

对每个要续写的 `work_id`，先执行：
```
py -3 build_context_bundle.py <work_id>
```
它会读取 `public/data/originals/<work_id>/ep*.json`，生成
`originals_source/<work_id>/context_bundle.md`，包含：
- 所有已发布集的结构化摘要（人物、beat、字数、首段提示）
- 最近 3 集（或总集数≤5时全集）完整正文
- 来源标注：集号、标题、字数

写作时**必须**带上这个文件：`--file context_bundle.md`。  
若上下文过长，脚本已按规则截断并保留最近几集完整正文，**不得**静默截断前文。
写完新集后，把新事实追加进 `facts.json` 的 `pending` 区（写作者**绝不直接改正式表**；
晋升由管线在上线后执行。`pending` 条目须带 `section` 分类、`source` 集号与 `awaiting` 集号）。

`section` 只许取这六个值，管线按它决定放进哪张表：

| section | 放哪个键 | 例 |
| --- | --- | --- |
| `open_hooks` | `hook` | 还没回收的钩子 |
| `facts` | `fact` | 前文立下的机制、规则、发现（不是时间点、不是道具） |
| `timeline` | `when` + `event` | 某个时间点发生了什么 |
| `props` | `item` + `holder` | 某件东西现在在谁手上 |
| `characters` | `name` + `pronoun` + `role` | 新出场人物的代词 |
| `numbers` | `value` + `meaning` | 新确立的数字 |

```json
{"section": "facts", "fact": "封签箱认温不认章：烫纸封不上", "source": "ep10", "awaiting": "ep11"}
```

写 `section` 不是可选装饰：缺了它整条事实进不了正式表，只会一直堆在 `pending`
里越积越多（2026-10-11 查到时已积 65 条、全部无 `section`）。同一条事实若后来
有更新版本，用同一开头重写一遍并更新 `source`；管线按 `source` 取较新那版。

## 3. 怎么写

- 先说可命名动作与听者/道具变化，再写一条可命名运镜动作与一句理由（不写“电影感推进/自然微动作”这类空话）。
- 对白不对口型独白；独白分轨或后期叠。
- 每集 1000～1500 字（含对白和括号动作），结尾必须留钩子。交稿前自己数一遍正文字数：
  低于 900 字视为不合格，重写一次（只重写一次；仍不合格就按实际交稿，并在末行 JSON 摘要里如实写 `min_words`）。
- 每集至少 3 个可拍的具体画面点（道具、光线、倒计时），写完自己数一遍，不够就加。
- **写作命令必须同时附带**：
  ```
  --file DAILY_DIRECTIVE.md --file originals_source/<work_id>/context_bundle.md
  ```
  新集输出为 `work.json` 里的新 `blocks`（不直接写 HTML）。

## 4. 写后：结构校验 + 叙事连续性审核（双门）

### 4.1 结构校验（现有）
```
py -3 build_originals.py
py -3 verify_originals_batch.py
```
失败即停，只修格式不改剧情。

### 4.2 叙事连续性审核（新增强制门）
对每个新生成的 `<work_id>/<ep_id>`：
1. 先用 `build_originals.py` 把新集渲染为临时 HTML（不写入 public）。
2. 跑只读审核：
   ```
   py -3 run_audit.py <work_id> <ep_id>
   ```
   它会同时读取：
   - `context_bundle.md`（前文）
   - 临时 HTML（新集）
   - `AUDIT_PROMPT.md`（审核规则）
   仅输出严格 JSON：
   ```json
   {"status":"PASS|FAIL","issues":[{"type":"...","severity":"CRITICAL|MAJOR|MINOR","episode":"epXX","description":"...","evidence_before":"...","evidence_after":"..."}]}
   ```
3. 解析失败 / 超时 / 模型报错 / 非 JSON / 字段缺失 → **视为 FAIL**。
4. `issues` 中只要有 `CRITICAL` 或 ≥2 个 `MAJOR` → **FAIL**。
5. 只有 `MINOR` 或空 → **PASS**。
6. FAIL 时：把审核报告追加到 `audit_failures.json`，**阻断部署**，保留草稿与报告，**不覆盖**已发布集。

## 8. 爽文笔法（2026-10-05 接入《爽文剧本写作指南》第六节原文，逐字）

```
【体裁】爽文剧本格式。保留「场景｜光｜在场」头与括号动作，不改写成小说叙述。

【节奏】每集走一个完整的小循环：开场即危机 → 压 → 憋 → 破 → 围观反应 → 余震 → 半截钩子。
「压」必须给对方具体筹码，不许一句话就把对方打发。

【对白】短句，一行一句，能互相打断。禁止角色一口气讲完规则、程序或阴谋；
信息拆成两三个来回，用对抗带出来。配角捧哏只留一句。

【画面】每集至少 3 个可拍的具体画面点（道具、光线、倒计时），不写心理活动。

【幽默】每场 1～2 个笑点：公文腔荒谬、规则荒唐但严格执行、吐槽役、高燃被小事打断、弹幕接梗。
选一个回调梗，贯穿全集。笑点放在泄压处，不放最紧张的拉扯里。

【内涵】允许字面正经的歧义双关，每场至多一处。
禁止直白性描写、露骨暗示、身体部位描写。

【钩子】只露半截，留问题，不给答案。禁止用电话/通知把下一集要做的事全说完。

【连续性】人物性别、身份、关键数字、时间线以「事实表」为准，写前先对表。
```

本节与事实表、连续性规则、“补到最高集号”规则并存，冲突时以事实表为准，字数与画面点按第 3 节硬指标执行。

2026-10-05 试跑追加（同样是硬约束）：
- 「破」不许演讲：主角连续说辞不得超过两段，中间必须有对手的反应、还嘴或动作；不许对手全程沉默听完。
- 格式不许漂移：叙述段不得超过两行；一切动作、表情、镜头一律用括号行或【特写】【音效】【弹幕】行；钩子段也用剧本行，不写叙述总结。
- 推理不许旁白代讲：关键推理只许角色说半句，剩下的留白给观众/下一集；禁止用叙述段把答案喂完。

### 8b. 集的脊梁是「翻盘」，不是「对物证」（2026-10-11 用户指出后加，据网文节奏方法论重写）

**为什么加**：实测五部作品的每一集 `beat`，ep01–04 全部是爽文节拍——
先问矿工欠了几个月工资、赔率最高时下坑、当众撕封条、当场点亮矿脉、
一块钢板报出三十万、全星直播问遗言。**从 ep05 起整体转向**：核对笔迹、
页脚上的日期、存根眉批八个字、封签箱吐出还印小票、手环编号对上空栏。
52,871 字里「程序类」词 175 次、「爽感类」词 32 次。审核侧同期给出
CLUE_MISPLACED 25% + TIMELINE_CONFLICT 15% 的判据，而没有任何一条奖励爽。

根因是结构性的，不是模型不会写。**用冲突驱动代替时间线驱动**——剧情枯燥的
标准解法是换场景、加新角色、升级体系、制造危机，没有一条是「多查一点证据」。
但本项目的事实表记的是人物/数字/时间线/道具/未收钩子/禁区，
「升级、阶梯、对手、反派、地图、阶段」**全部 0 次命中**：
表里只有「不许弄坏」和「必须收尾」，没有一条说「这集必须比上集更难」。
加上设定天生带一个要查的阴谋，`open_hooks` 就把剧情一路往「查清楚」拉。

**所以本节管的是节奏和场面，不是禁令清单。** 按行业标准写：

**一、每集走「起承转爽」，不许走「信息揭露递进」**

第 8 节的「开场即危机 → 压 → 憋 → 破 → 围观反应 → 余震 → 半截钩子」
就是起承转爽，照走。四段各有硬要求：

- **起**：一句话说清这一集谁在压她、凭什么压。压必须**具体且有人在场**——
  对方是谁、他手上有什么、谁在看。只有抽象障碍（系统、规矩、命运）压着不算。
- **承**：压力**要升**，不是重复。第一次被压和第二次被压必须是不同的难，
  筹码要变（大人物出面、加规则、扣钱、扣人、限时）。原地重复的压力等于没压。
- **转**：反转来自**她自己**——她提前埋的东西、她拿出来的底牌、她算好的那一步。
  不许靠外力降临解围，不许靠新证据突然出现。
- **爽**：她当场翻回来，**当着人**。「当场」是关键词，不许留到下一集。

**明确禁用「信息揭露递进」模板**（线索A→结论1→发现不对劲→线索B推翻→更大秘密）。
那是悬疑/解谜的章节模板。本项目五部作品从 ep05 起跑的就是它，
所以读起来像名侦探柯南。线索可以出现，但**线索是她翻盘用的东西，不是本集要完成的任务**。
反例（踩过的坑）：`配钥匙铺齿模单与铜屑对上井底锁芯新痕`——这是一个比对任务。
正例：`她把齿模单拍在柜面上 · 半条街回头 · 师傅当众认出那支笔`。

**二、爽点要有密度，还要能延伸**

- **每集至少一个小爽点**；**每 3 集一个大爽点**。断了就掉追读。
- **爽点不写完就等于没写**。翻盘只是开始，后面还要延伸：
  清点收获 / 超出预期的收获 / 用收获去震惊围观的人 / 围观的人改变态度。
  第 8 节的「围观反应」就是干这个的，不许写成一句「众人骇然」就带过。
- **爽点类型不许连着重样**。打脸、解谜、撒糖、搞笑日常、新威胁轮着来，
  连着五集打脸会审美疲劳。
- **回收即新爽点**：埋了很久的东西这一集收回来，那一下要比当时埋更响。

**三、张弛 3:1**

- 连续高压 3 集，第 4 集给一点喘息（日常、关系、休整），
  **喘息集也必须有小爽点**，不许写成注水章。
- 喘息不是放松警惕，喘息里要埋下一个新的、更大的压力。

**四、压力必须跨集升级（这条最容易犯懒）**

- 每 3 集要有一次**对手或赌注的实质变化**：新的人上来、钱变多倍、
  期限变短、从「被刁难」变成「被通缉」。跳过的三集等于没发生。
- 不许用同一个对手、同一种刁难连着写超过 2 集。
- 主角这一集赢下来的东西，要变成下一集她被压得更狠的原因。
  **这一条是全篇最重要的一句**：赢一次，代价要留到下一集还。

**五、场面要动起来：打斗、鬼物异象、金手指开到超常识（2026-10-14 拆开）**

用户明确要求：剧情要一个接一个，**包括打斗场景、鬼物异象**。
实测 60 集里动作词只有 43 处，`tingjijia` 全程 4 处——**等于没有打斗**。

这里原本只有一条「奇幻事件」，而它被定义成「把金手指开到超出常识」。
**这条定义把用户说的鬼物/异象整个排除在外了**——异象不是她的能力做得多好，
是**有东西在那里**。指令可以被完全遵守，而衡量异象的数字一动不动：
五部作品 0.10/千字，卡了很久。原因是尺子和指令量的不是同一件事。
现在拆成三条，各自独立算数。

- **（1）每 3 集至少一次「身体动起来」的场面**：抢、夺、追、拦、破门、拆、砸、
  当众把实物硬夺回来。不算打斗的写法：「双方对峙」「气氛骤然紧张」「他的手握紧了」。
  打斗用**短句三连**（他拔剑。寒光一闪。血溅三尺。），不用长句写心理。

- **（2）每 2 集至少一次「不可解释的东西在场」——鬼物、异象、说不通的事。**
  这是用户点名要的东西，也是五部作品长期最缺的一项。
  **它不是「她查出来一件怪事」，是「怪事本身在场」**：凭空、凝成、缠上、
  渗出来、长了什么东西、慢了半拍、比她先动、睁开眼、化开、冻住、烧穿、裂开。
  三条硬要求：
  ①**有人看见了**——不是她一个人偷偷觉得不对，是在场的人看见了，包括对手；
  ②**说不通**——当场没有人能解释它，先记着，不许当场解释掉；
  ③**它要起作用**——下一集它必须还在：要么变成筹码，要么变成代价。
  写不出来的时候写**一件小的、说不清的**：桌角自己湿了一小块、
  影子先她一步抬手、通话那头有人在她这边说话。小的也行，没有不行。

- **（3）每 3 集至少一次「金手指开到超常识」**（原来的那条，现在独立）：
  别人做不到、她当场做到，且有人亲眼看见。
  这是她的**职业能力**（钢板会说话、听机甲、认配方）开到超常识，
  和（2）不同：（2）是世界在动，（3）是她在动。

- 打斗、异象、金手指**都必须有观看任务**：这几秒看什么、谁在场看见、
  看的人态度怎么变。
- 它不是另起一段，是**「转」那一下的形态之一**——她靠身体、靠异象、
  或靠金手指当场翻回来。

**六、换地图与升级阶梯**

- 每 5 集要有一次**空间推进**：从矿区进旧城、从受理厅上船、从地面下到井下。
  实测每部作品的活动范围只有 1–2 个星域，`tingjijia` 全集没离开 `帝星`——
  长期不换地图，读者感觉不到故事在往前走。
- `pressure` 段要能回答**「她这一格爬到哪、下一格是什么」**：从借设备到有执照、
  从被告到有产权、从打工到有股份。**资产一格一格往上走，不能只在原地吵赢。**
  实测 `tuiqun`、`zhenqianjin` 正文里阶梯词 0 命中。

**七、边界**

- 连续性照旧：人物、数字、时间线、道具仍以事实表为准。
  **但本节优先于「要收完 open_hooks」——不许拿「要守连续性」当理由把本集写成核对记录。**
- 未收的钩子可以留，但要**带着压力留**（「因为上一件事没结，她现在更被动」），
  不许写成「她开始查上一件事」。
- **这一节不是禁令堆**。上面每一条都是为了同一件事：
  让读者的情绪跟着被压下去、再弹起来。判断标准只有一条——
  **读完这一集，读者是「爽到了」还是「又查了一堆东西」？**

## 9. 总纲：这是爽文，奇思妙想没有禁区（2026-10-06 用户口授）

> 记得咱们是爽文，要的就是奇思妙想，发挥你的想象，在这里没有什么是不可能的。

- **放开写**：设定、机构、道具、程序、反转，怎么大胆怎么来。公文里能长出离谱的科室，规矩能荒唐到好笑，小人物能接住天上掉下来的运道——爽文的“爽”来自想不到，不来自四平八稳。
- **每集至少埋一个“没想到”**：一个读者看到会“啊还能这样？”的点子（新机关、新玩法、身份反转、规则的第二种用法）。写完自检：本集最妙的点子是什么？答不出来就再想。
- **“没有不可能”的边界只有一条**：不推翻事实表里已确立的旧事实（人物、数字、时间线、道具状态）。旧设定不许复活、不许打架；除此之外，新东西尽管往上加——新事实写进 `pending`，管线审核上线后自动转正。
- **审核不拦想象力**：文笔审核只记录不拦单（内涵越界除外）；连续性审核只查“与前文矛盾”，不查“脑洞太大”。脑洞大不是错，矛盾才是错。
- 想象力与第 3 节硬指标（1000～1500 字、≥3 画面点、钩子）并存：脑洞要落成具体的画面和道具，不是形容词堆砌。

2026-10-06 追加口授（同样是总纲，进每一集的写法）：
- **科幻底色**：舞台是域外星际——公文、程序、船、井、档案这些日常物，全都长在科幻上
  （终端、封签箱、航路矩阵、矿星、应急灯海）。设定怎么新奇怎么来，科幻不是点缀，是空气。
- **一言不合就动手**：冲突升级要快，能动手不动嘴。拍桌、掀单、撕页、按住不放——
  用动作打断对话，别让角色把话说完。打架、掀桌子、当场翻脸，都是正常推进手段。
- **智商在线，人却很傻**：人物要聪明——算得清账、看得懂规则、抓得住漏洞；
  但一到利害关头就犯蠢：自作聪明、低估对手、贪小便宜、嘴硬不认。聪明给“爽”，犯蠢给“戏”。
- **能力不够，外挂来凑**：主角正面实力不够是常态，赢要靠外挂——系统、道具、身份、
  规则漏洞、别人留下的后手、天上掉下来的机会。外挂要具体（一件道具、一条规则、一个身份），
  不许写成“突然顿悟”；外挂也要有代价或限制，下一集能再咬一口。
- **男主好色**：好色是他的人味和笑点来源——见漂亮走不动道、嘴上占便宜、被拿捏后又怂又撑。
  写法上限：字面正经的歧义双关与喜剧反应（第 8 节【内涵】条款原样有效）；
  禁止直白性描写、露骨暗示、身体部位描写——这条是硬拦单红线，好色止于“眼神、嘴、怂样”，不越线。
- **女主漂亮带绿茶感**：好看是事实（写在场面里：全场回头、灯光偏她），绿茶是手段——
  说话滴水不漏、示弱藏刀、借刀杀人、笑着说最狠的话。绿茶感靠对白和分寸表现，
  不靠外貌形容词堆砌；她得真有脑子（智商在线），绿茶是她的武器不是她的全部。
- **对白必须像人话（2026-10-06 追加，最重要的一条）**：写完每句对白默读一遍——
  这话能直接从嘴里说出来吗？说不出口就改。
  - 禁 AI 腔：书面连接词（“紧接着/与此同时/事实上/显然”）、成语堆叠、排比对仗、
    金句总结、破折号后给自己补注释（角色不会边说话边写文章）、“目光中闪过一丝”这类描写腔。
  - **禁“虽然…可是/可/却”成瘾（2026-10-10，实测加的）**：叙述里反复用同一个转折
    骨架，是这批稿子最明显的机器指纹。实测 ep11 有 6～11 处，全是“虽然…可…”；
    ep01–ep09 是 0 处。同一转折骨架**一集最多两处**。要转折就换骨架：后半句直接
    顶上来不接头词、或断成独立短句。**对白里不受限**——人说话本来就说“虽然”。
    写完数一遍（`connective_gate.py` 会替你数并卡住上线）。
  - 正常人说话：短句、半句、话说一半被打断、答非所问、先应一声再答（“啊？”“急什么”“你说完没”）、
    重复对方的词再反问。语气词是活的：吧、呢、嘛、呗、啊。
  - 说话带身份：算账的满口账，管册的满口册，粗人不文绉，文化人酸到底——
    同一件事，五个人五种说法。
  - 交稿前抽查：任选三句对白念出声，有一句像“写出来的”而不是“说出来的”，全篇回改。
- **打碎完美逻辑，注入主观偏见与瑕疵（2026-10-06 追加）**：AI 味的另一根骨架是
  “叙述太公平、人物太周全”——谁都不偏心，说话都占理，事件都因果严丝合缝。人不这样：
  - **叙述带立场**：挑一个在场者的偏见跟着写（他觉得丢人的事，叙述就往难堪里写；
    他不信的事，叙述就带一句“也就那样”）。不许裁判式上帝视角给每个人等量笔墨。
  - **人物有瑕疵**：主角会嘴硬、会迁怒、会记仇、会自我安慰；配角会甩锅、会犯懒、
    会把道听途说当真。一句台词里允许带点私心——人说话从来不是为了信息最优化。
  - **因果留毛边**：不是每件事当场都有解释。允许误会、记错、道听途说、想当然——
    人物基于错误信息做决定，比“人人算无遗策”更像真事。但**事实表的硬数字不许错**：
    毛边给观点和传闻，不给关键数字与时间线。
  - **判断允许双标**：人物可以一边骂这事不合理，一边干同一件合理的事——
    自己干的就找理由，别人干的就挑刺。这是人，不是逻辑课。
  - 自检：读一遍叙述，若出现“显然/事实上/毫无疑问”这类裁判腔，删掉，换成某个角色的偏见。
- **句式长短拉伸（手风琴节奏，2026-10-06 追加）**：字数达标但读起来像电报，仍是不合格。
  - **拉长环境与心理**：不许两三个字交代动作。写心虚、打算盘、收纸这类段落，
    允许“虽然……但……”“索性……干脆……”的复合长句，把内心的拉扯感写满。
  - **短句留给刀刃**：只有台词交锋、红字突然灭掉、秘密被戳穿的瞬间，
    才许用 5 字以内的极短句制造“啪”的冲击。极短句是稀缺资源，一集不过三五处。
  - 整篇像拉手风琴：有舒张，有紧缩。写完自检——若连续三行都是短句，加长；
    若一段超过六行没有一处“啪”，劈开。
