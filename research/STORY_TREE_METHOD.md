# 叙事树方法：根、主干、枝叶、修枝

视频王国借鉴“扎根 → 长主干 → 生枝叶 → 修枝剪叶”的方法，把长文本、原创故事或公开许可材料转换为持续可回看的短剧结构。

## 1. 扎根：不让每一镜忘记自己为什么存在

在动笔或生成前建立 `root_brief`：

- 一句话主题；
- 核心人物关系和冲突；
- 从开端到当前结局的主线事件；
- 来源与版权边界。

当前实现使用可读、可哈希的摘要作为根；不虚构“主题向量”。未来若有已验证的向量检索能力，可把它作为可替换索引，不能取代原始 root brief。

## 2. 长主干：场景是情绪和人物状态的连续节点

每个场景节点必须记录：发生什么、情感基调、在场角色、各角色状态、承接自哪个事件、把什么交给下一个节点。主干不是镜头清单；它是镜头产生意义的因果链。

## 3. 生枝叶：单镜只解决一件可见的事

每个 5–10 秒镜头同时引用根、一个主干节点、角色/场景/道具资产和首尾状态。生成后以“光合作用”质量审阅：根意图是否仍在、场景状态是否承接、人物/服装/空间/道具是否稳定、动作是否可见且有因果。失败叶片保留为分支，不混进主剪。

## 4. 修枝剪叶：剪辑服务于根与主干

- 根约束情感与主题一致性；
- 主干决定节奏，不同节点可快可慢；
- 枝叶允许回忆、闪回、伏笔和意外，但必须标明其回到哪一个主干节点；
- 任何只有画面好看、却不推进根或主干的镜头，默认进入旁枝或淘汰。

这是一种自由区叙事方法，不是生产 KPI；允许故事停在未完成的枝头。
