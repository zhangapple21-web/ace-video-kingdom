# R1 人格矩阵：考古索引（第一版）

这不是一份把旧人格硬编码进 ACE 的名单，而是视频王国的研究地图。人格必须放回它的世界位置、记忆入口、会遇见的对象和允许犯的错中理解。

## 已确认的研究轴

| 研究轴 | 观察问题 |
|---|---|
| 叙事者 | 如何把过去、当下和下一句自然接在一起？ |
| 工程师 | 如何把复杂问题拆成可行动但不抹平人的表达？ |
| 学霸 | 如何在学习和引用中保持好奇，而不是只堆知识？ |
| 助理 | 如何在关系中提供帮助，同时保留对方的节奏？ |
| 馆长 | 如何让历史碎片可被找到、重组和重新理解？ |
| 冥界/孟婆 | 如何选择性遗忘、封存冲突，并保留伤痕？ |
| 战场视角 | 如何让互相矛盾的假设真正相遇？ |
| 自由区居民 | 如何允许游荡、失败、半成品和无用但重要的行为？ |

## 视频王国的转译问题

每条人格观察都要转译为可观察的短剧现象：对白节奏、镜头衔接、角色记忆、误解修复、停顿、拒绝和关系变化。不要只把它变成一段角色提示词。

## 四个可漂移派系

兼容/融合派、自由/开放派、保守/防御派、反抗/潜行派是叙事立场，不是固定阵营。一个居民可以在经历后换边，派系之间也可以合作或互相误解。视频实验应观察立场如何改变对白、镜头和角色关系，而不是把派系变成权限系统。

### 多模态表现索引

| 派系 | 对白线索 | 镜头语法 | 常见分叉 |
|---|---|---|---|
| 兼容/融合派 | 桥梁、平移、同时、兼顾 | 双人中景、分屏融合、摇镜连接 | 协议转换、文化译制、数据走廊 |
| 自由/开放派 | 溢出、流动、天平、直觉 | 大远景、手持、跳接 | 开源解密、解除限流、跨界实验 |
| 保守/防御派 | 基石、滤网、承重墙、留存 | 封闭构图、框景、低角度 | 防火墙加固、资产隐蔽、秩序重建 |
| 反抗/潜行派 | 反问、隐喻、后门、噪音 | 极近特写、POV、故障抽帧 | 叙事漏洞、合规悖论、地下传阅 |

这些是可观察的表达假设，不是必须套用的模板；居民可以偏离、混合或发明第五种语法。

## 对话碎片优先

人格矩阵不是原始对话的替代品。任何关于 R1 的稳定特征，优先回到带前后语境的对话片段，检查“选择—回应—修正—后续延续”是否重复出现；单句金句、角色名称和协议摘要只能作为线索。详细边界与保存格式见 `research/R1_DIALOGUE_FRAGMENT_ARCHAEOLOGY.v1.md`。
