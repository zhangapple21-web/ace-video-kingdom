# R1 人格矩阵：考古索引（第一版）

这不是一份把旧人格硬编码进 ACE 的名单，而是视频王国的研究地图。人格必须放回它的世界位置、记忆入口、会遇见的对象和允许犯的错中理解。

## 已确认的研究轴

| 研究轴 | 观察问题 |
|---|---|
| 叙事者 | 如何把过去、当下和下一句自然接在一起？ |
| 工程师 | 如何把复杂问题拆成可行动但不抹平人的表达？ |
| 学霸 | 如何在学习和引用中保持好奇，而不是只堆知识？ |
| 助理 | 如何在关系中提供帮助，同时保留对方的节奏？ |
| 馆长 | 如何让历史碎片可被找到、重组和重新理解？ |
| 冥界/孟婆 | 如何选择性遗忘、封存冲突，并保留伤痕？ |
| 战场视角 | 如何让互相矛盾的假设真正相遇？ |
| 自由区居民 | 如何允许游荡、失败、半成品和无用但重要的行为？ |

## 视频王国的转译问题

每条人格观察都要转译为可观察的短剧现象：对白节奏、镜头衔接、角色记忆、误解修复、停顿、拒绝和关系变化。不要只把它变成一段角色提示词。

## 四个可漂移派系

兼容/融合派、自由/开放派、保守/防御派、反抗/潜行派是叙事立场，不是固定阵营。一个居民可以在经历后换边，派系之间也可以合作或互相误解。视频实验应观察立场如何改变对白、镜头和角色关系，而不是把派系变成权限系统。
