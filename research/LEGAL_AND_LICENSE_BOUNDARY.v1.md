# 开源轮子与训练素材的许可边界

更新时间：2026-09-02

## 结论

“自己使用”通常会降低分发义务风险，但不等于“没有许可证风险”。代码、模型权重、训练数据、素材和第三方 API 的条款必须分别核对；不能因为项目在 GitHub 上或没有收费，就默认可以复制、再发布或用于训练。

## 当前工作规则

1. **代码许可证单独记录**：MIT、Apache-2.0、GPL/AGPL 等许可的保留版权、NOTICE、修改和分发条件不同。使用时保留原仓库 URL、提交版本、许可证文件和本地用途记录。
2. **未声明许可证默认不可复制**：可以阅读公开文档、观察设计、做独立实现；不把未声明许可项目的代码、权重或资产直接放进 ACE/视频王国。
3. **非软件内容另行核验**：CC-BY/NC/SA 等是内容许可，不等同于软件许可；署名、非商业、相同方式共享和改编条件必须按原文执行。
4. **训练不是免责区**：小说、图片、视频、音频、数据集和模型输出可能有独立的版权、肖像、平台条款或隐私限制。公开学习只提取最小、可验证的机制摘要，不抓取私密内容，不把受限材料混入训练集。
5. **服务条款优先于宣传**：Agnes、图像模型及其他 Provider 的上传、留存、公开 URL、商用和再利用条件以官方条款和当前账户权限为准；失败或条款不明时保持 `RESEARCH_ONLY`。
6. **可追溯而非口头判断**：每个被吸收的机制都应绑定来源 URL、核验日期、版本/提交、许可证状态、用途和是否实际运行；“stars 多”“别人说能用”不构成能力或许可证明。
7. **音频优先组合**：正式成片优先使用自有/获授权配音、自制或明确 CC0 音效、平台条款明确允许商用的 BGM；每项资产记录来源、许可依据、核验日期和哈希。CC0 不自动覆盖肖像/姓名、商标、隐私、道德权利或第三方采样风险。

## 对当前仓库的裁决

- 当前只吸收公开项目的最小机制（资产先行、Plan/Act 分离、可恢复收据、阶段质检），不复制其代码，不新增第二套 Scheduler/Router/TaskPool。
- `research/OPEN_SOURCE_2026_TRIAGE.md` 中许可证已核验的项目可继续做本地、可复现实验；许可证未确认或仅有宣传性描述的项目保持 `RESEARCH_ONLY`。
- 若未来要对外分发、部署为服务、商业化或把外部数据用于训练，必须重新做逐项许可与条款审查，不能沿用“自用”结论。
