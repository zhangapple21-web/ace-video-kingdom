# 自由区公共知识层

视频王国虽然有独立的房间和 Git 仓库，但不与其他项目隔绝。它可以借阅代码研究、人格考古、量化假设、系统失败和其他项目的故事；其他项目也可以借阅视频王国的镜头语法、角色连续性和自然对白实验。

每次借阅都要保留来源项目、原始产物、指纹、时间和借阅项目。允许魔改、反驳和拒绝，不允许静默复制，也不允许把单个项目的局部结果冒充整个自由区的真理。

共享的是摘要、方法、失败和问题，不是私密原文、凭据或未经允许的原始载荷。

公共层也共享“小灶方法”：专项蒸馏的案例设计、失败清洗和表达结构，以及安全红队发现的失效模式。红队只研究误判和防御改进，不提供绕过安全、付费或访问控制的方法。
