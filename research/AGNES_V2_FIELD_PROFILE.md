# Agnes Video v2.0：现场能力画像

更新时间：2026-09-01。此文只根据本仓库的真实调用、媒体文件、公开首页和只读接口发现写成；不将营销描述当能力事实。

## 已验证事实

- `agnes-video-v2.0` 已成功完成 9 个独立任务；每个任务有持久化 `video_id`、终态 `completed`、可下载 `video/mp4` 和 SHA-256。
- 当前输出样本均约 **5.041667 秒**；最终重编码成片为 1088×832、24fps、H.264 + AAC。
- 模型能在单镜里产出有电影感的光照、酒馆环境、玻璃材质、人物动作和安静情绪；这由 2026-09-01 的 45 秒接触表和单镜文件可复核。
- 当前免费通道曾观察到 `1 request/minute` 限流，且一次创建获得 HTTP 503；执行器现在会按 `Retry-After` 或 60 秒恢复。
- 公共网页检索只确认 Agnes 是免费多模态 API 网关。`/docs`、`/openapi.json`、`/.well-known/openapi.json` 返回 403，`/v1/openapi.json` 返回 404；当前无公开可读的 `agnes-video-v2.0` 参数契约。

## 现场推断：适合承担什么

**适合作为短剧的“叶片镜头”渲染器：**

- 单地点、单时段、一个主体或一个主体加一个静止道具；
- 5 秒内只有一个可见动作：放杯子、转头、停顿、开门、光线变化、反应镜、空镜；
- 氛围建立、人物反应、道具特写、转场和余韵；
- 镜头自身完整，而不是承载整段对白、转场、剧情解释和多角色调度。

## 已观察弱项与禁止误用

- 45 秒九镜粗剪中，跨镜人物脸、服装、桌面和空间布局发生漂移；它不能被当成角色连续性渲染器。
- 不要用它单镜承担多人物对白、精确口型、复杂群像、跨场景时间跳跃、长因果链、画面文字或数量/布局硬约束。
- **参考图、首帧/尾帧、图生视频、角色 ID 锁定、音画同步**当前均为 `UNVERIFIED`；不得猜参数或把文字描述说成参考驱动。

## 对症使用规则

1. 先由角色衣橱、场景资产和分镜铺完成可复核合同。
2. 如果镜头必须保持身份/场景，先验证 Provider 是否真正接收并使用参考图；验证前把 Agnes 用于无身份风险的空镜、反应、道具或过场。
3. Agnes 提示词采用 **一个地点 + 一个主体 + 一个动作 + 一个镜头 + 一个结束状态**；不塞入多个剧情节点。
4. 输出后先经连续性审阅；符合单镜质量但不符合跨镜锚点的，可作为支线/过场保留，不能进入主线。
5. 对有参考约束的主线镜头，在支持参考资产的候选模型上做小样 A/B；只有实测改善才调整 Provider 角色。

这是一份隔离研究的能力分工，不是生产路由或成本承诺。
