# 原创桌 · 分轨目录

研究是为了写出可读剧本，不是为了堆笔记。
观众爱看哪一部，事先没人知道，所以分轨试写，互不合并世界观。

全剧硬门槛见 ALIVE_SCRIPT_GATE.v1.md。不管写哪部，先过三问：观众第一感、有没有 AI 感、想不想往下看。过不了就重写。
再过对白：戏在对白里顶；对白要沉；轻飘飘的删。占比高不是注水。冲突驱动不是拉长器：人物互相施压，收场必须有变化。一集弧光见 docs/KEEP_HARD_ROAD_ARC.v1.md：卡死→劝退→守住→做实→见光→归位→留白，不套七环填空。

## 先懂人，再讲故事

不要靠套路、节奏、时长撑场。先写这个人不肯将就、不肯低头、不肯放下的那一点。
软要有没处说的地方，狠要有没处发的地方，盼要有没处等的地方。
沙盒里推的是活人，不是功能句。
人味：先要一样东西，付代价，还不将就。
AI味：先讲规则，再给反应，再用比喻解释情绪。
戏在对白里顶。对白要沉。一眼看懂、一拳到位，别品。

冷落在日常生活的异化，不写空洞地府阎王。开场用认知/视觉反差，禁止拖沓探案。超自然现世报只给冷爽桌，不灌残荷。
