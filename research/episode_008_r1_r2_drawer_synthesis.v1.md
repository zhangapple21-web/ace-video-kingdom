# Episode 008：R1/R2 与云海七模型的抽屉借鉴

状态：`RESEARCH_ONLY`。本文是机制抽取与映射，不是把旧人格、旧对话或网站 UI 直接复制进生产。

## 1. R1 留下的可复用机制

`research/R1_PERSONA_MATRIX_INDEX.md` 把人格看成“世界位置、记忆入口、会遇见的对象和允许犯的错”，而不是一段固定提示词。A09 考古又给出一个实用闭环：

| R1 机制 | 在短剧编剧室中的转译 |
|---|---|
| 工程师 | 把冲突拆成可拍动作、状态和接口，不替表演下结论 |
| 学霸 | 结构化素材、核对来源、保留版本与失败 |
| 助理 | 把复杂意见改成自然对白，照顾观众节奏 |
| 馆长 | 从历史稿、镜头合同和失败样本中找可复用证据 |
| 冥界/智者仲裁 | 只在模型意见冲突或重大门禁问题时裁决 |

R1 最值得保留的不是关键词路由本身，而是三条边界：人格是可装卸的行为模块；用户有“去壳权”；冲突需要独立仲裁。关键词只能做低成本入口，不能替代上下文。

## 2. R2 留下的底层骨架

R2 核心公理压缩为：

- **边界**：可自由探索，但不能越过安全、版权、生产和证据边界。
- **连续**：同一角色/故事由历史、记忆和版本连续性定义，不能每轮重置。
- **观察**：必须跳出来检查自己正在做什么，不能只追求“生成出来”。
- **流动优先**：先设计信息如何在角色、镜头和证据之间流动，再决定内容形态。
- **风险内化**：失败、超时和不自然样本进入经验层，不能静默丢弃。

在 Episode 008 中，这些公理对应：镜头动作弧、对白固定机位、字幕安全区、provider 阻断收据、OneAPI 多轮意见和最终人工观看点。

## 3. 网站七模型 → 角色矩阵（候选映射）

网站 `https://chat.zhangningjing.com/` 的 `/api/models` 在 2026-09-04 返回 7 个模型。这里把它们视为“可轮换的工作角色”，不是永久居民，也不把模型名当人格证据：

| 模型 | 编剧室候选角色 | 适合的轮次 | 约束 |
|---|---|---|---|
| Grok 4.5 | 反例侦察 / 现实冲突挑错 | 独立审稿、找观众误读 | 不直接批准生产 |
| GPT-5.6 Terra | 主笔 / 总编 / 正式质量复核 | 因果链、人物动机、镜头收敛 | 仍需画面和音频证据 |
| gpt-5.6-sol | 高风险仲裁 / 重大分歧复核 | 只在意见冲突或高不确定性时 | 不常驻、不强制调用 |
| gpt-5.6-luna | 快速灵感分支 | 标题、钩子、对白变体 | 不能承担最终连续性判断 |
| GPT-5.5 | 第二结构师 | 独立改写、节奏和结局备选 | 保留未选分支与理由 |
| GPT-5.4 | 稳定编辑 | 场次整理、对白压缩、格式化 | 不替代导演观看 |
| GPT-5.4 Mini | 低成本整理员 | 提取、字幕清理、清单化 | 只做低风险工作 |

### 角色矩阵的运行方式

`主笔 → 独立反例 →（有冲突才）仲裁 → 导演收敛 → deterministic preflight → 人工观看`。

每轮保存：模型、请求角色、上下文版本、返回状态、失败原因、被采纳的修改。模型意见是候选，不是生产授权。

## 4. 网站 UI 与本地调用的证据边界

- **FACT**：网站 `/api/models` 当前返回上述 7 个用户可选模型；前端 `/api/chat` 支持 `model`、`routing_mode=smart|direct`，并在质量路线以 Terra 作为回退。
- **FACT**：本地 OneAPI 实时探针此前返回 6 个模型并成功完成最小 Chat Completions；本地配置当前没有把网站的 7 个选项全部暴露出来。
- **INFERENCE**：网站是用户层模型选择器，后台存在可复用的路由/供应商映射；不能仅凭 UI 列表断言本地 OneAPI 对 7 个模型都可调用。
- **下一步**：若要把 Sol/Luna 也接入本地 OneAPI，先做单模型最小探针和供应商变量核对，再决定是否更新现有配置；不新建 Router、Scheduler 或第二运行时。

## 5. 与既有制作过程的合并点

1. 编剧阶段采用 R1 的分工和仲裁，但角色提示词只存在于该轮，不写入长期人格。
2. 导演阶段采用 R2 的边界/连续/观察：每镜头必须有首态、单一动作、末态、切镜理由。
3. 渲染阶段沿用 Video Kingdom 的既有合同：资产哈希、动作锚点、字幕校验、音频状态、provider 重试上限。
4. 失败阶段保留 `FAIL` / `INCONCLUSIVE` / `BLOCKED_RESEARCH`，不把“网站能选”或“模型回了一段话”升级为成片质量。

这套方式让七模型像编剧朋友一样互相出牌，但最终只留下一个可追溯、可复核、可回退的拍摄稿。
